# Разработка

Каждый срез выполняется по TDD:

1. тест описывает один ожидаемый результат;
2. минимальный код делает тест зелёным;
3. имена и зависимости упрощаются;
4. выполняются `pnpm lint`, `pnpm test` и `pnpm build`;
5. изменённая граница фиксируется в документации.

Используйте простой английский и четыре пробела. Настоящие bot token, refresh token и данные людей в
тестах запрещены.

# ADR 0002: серверный callback для кнопок подтверждения

## Статус

Принято.

## Контекст

Карточка Channel Gateway содержит `actionId`, `payloadHash` и действия подтверждения. Передавать эти
значения прямо в Telegram callback небезопасно и неудобно: пользователь может изменить данные, а
Telegram ограничивает размер callback.

## Решение

Адаптер создаёт случайный UUID для каждой кнопки и сохраняет соответствующие `actionId`,
`payloadHash`, решение, владельца и срок жизни в PostgreSQL. При нажатии запись берётся во временный
lease. Она становится использованной только после успешного ответа Channel Gateway. При временной
ошибке lease снимается.

## Последствия

- Telegram не является источником параметров действия.
- Одно нажатие не обрабатывается параллельно несколькими worker.
- Временную ошибку можно безопасно повторить.
- Истёкший или использованный callback отклоняется.

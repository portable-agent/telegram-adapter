# Runbook

## Webhook возвращает 401

Проверьте, что значение `X-Telegram-Bot-Api-Secret-Token` совпадает с `TELEGRAM_WEBHOOK_SECRET`.
Не выводите секрет в лог.

## Команда `/link` не работает

Проверьте доступность Keycloak из контейнера и включённый Device Authorization Grant у клиента
`telegram-adapter`. Проверьте client id и secret без их вывода в лог.

## Сервис не запускается

Проверьте все значения из `.env.example`, доступность PostgreSQL и длину декодированного ключа
`TOKEN_KEY_BASE64`: ровно 32 байта.

## Нужно заменить ключ шифрования

Не меняйте ключ без процедуры re-encryption. Иначе сохранённые refresh token станут недоступны. До
появления ротации отзовите существующие связи и попросите пользователей выполнить `/link` снова.
